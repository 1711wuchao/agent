# 项目需求文档：Kimi 合同 Agent 系统

## 1. 项目目标

建设一个企业内部合同智能生成系统。系统通过 Vue3 前端提供业务操作界面，通过 Spring Boot 后端管理合同、模板、版本、审批、文件生成与 AI Tool 调用，通过 Kimi Agent 理解用户意图并调用自建 Tool 完成合同生成和辅助审查。

## 2. 用户角色

| 角色 | 主要能力 |
| --- | --- |
| 业务人员 | 创建合同、填写字段、生成草稿、提交审批、下载文件 |
| 法务人员 | 维护模板、审核合同、维护条款库、处理风险提示 |
| 审批人 | 审批、退回、查看审批记录 |
| 管理员 | 用户、角色、权限、系统配置 |
| Kimi Agent | 调用 Tool 查询模板、创建草稿、检索条款、生成建议 |

## 3. 核心业务流程

1. 用户自然语言描述合同需求。
2. Kimi Agent 识别合同类型和缺失字段。
3. Kimi Agent 调用后端 Tool 查询模板和必填字段。
4. 用户补充字段。
5. 后端创建合同草稿。
6. 后端填充 Word 模板并导出 PDF。
7. 用户提交审批。
8. 法务审核并归档最终版本。

## 4. MVP 功能

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 合同模板查询 | 查询启用模板和变量 | P0 |
| 合同草稿创建 | 根据合同类型与字段生成草稿记录 | P0 |
| Word 生成 | 使用 `.docx` 模板填充变量 | P0 |
| PDF 导出 | 将 Word 文件转换为 PDF | P0 |
| Kimi Tool 接口 | 暴露 Agent 可调用的工具 API | P0 |
| 合同版本 | 记录草稿、审核、最终版本 | P1 |
| 条款知识库 | 标准条款、风险条款向量检索 | P1 |
| 审批流程 | 提交、审核、退回、通过 | P1 |

## 5. 非功能要求

- 所有 AI Tool 调用必须记录日志。
- Agent 不能绕过权限、审批和版本控制。
- 模板变更必须保留版本。
- 合同文件应使用独立文件存储，数据库只保存路径和元数据。
- 生产环境必须启用操作日志、备份、鉴权和 HTTPS。
