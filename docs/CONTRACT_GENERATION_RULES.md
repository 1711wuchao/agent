# 合同生成业务规则

## 数据来源

- 支持根据 Excel 表格中的销售方、购买方、开票日期、品名、规格型号、数量、税率、价税合计生成合同。
- 同一开票日期归并生成一份合同。
- 合同日期按开票日期向前推算三个月确定。

## 合同类型判断

- 品名包含“站点”“软件”“算法”的，归为技术开发合同。
- 其他硬件或产品类记录，归为产品购销合同。

## 编号与格式

- 合同编号不得出现汉字。
- 购销合同页数目标为 3-5 页。
- 技术开发合同页数目标为 10-15 页。
- 生成不同版本格式的合同，避免任意两份合同格式超过 70% 雷同。
- 自动优化合同排版。
- 表格跨页时，后续页需要保留表头。

## 条款要求

- 合同付款分 2 期。
- 合同签订后支付合同总金额 70%。
- 项目验收通过后 90-100 天内结清合同总金额未付款项。
- 硬件产品类合同需补充国家验收标准等内容。
- 软件产品类合同需明确技术目标、技术实现路径、验收节点、验收标准。

## 禁止内容

- 合同内不得出现“参考”。
- 合同内不得出现“参考文献”及相关信息。
- 品名内不得出现“通用设备”。
- 合同内容不得出现“不含税金额”“税额”。
- 合同中无需体现企业地址、法人信息。
- 无需设置法人签字页。
- 盖章页不得包含表格。

## 必须体现

- 合同内容必须体现税率。
- 合同内容必须体现价税合计。
- 合同内容必须体现数量。
- 合同内容必须体现规格型号。
- 送货地址仅标注“甲方工厂内指定地点”。
