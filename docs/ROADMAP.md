# 从 0 到上线开发计划

## 第 1 阶段：工程与 MVP 闭环

- 完成前后端工程骨架。
- 完成合同模板查询。
- 完成合同草稿创建。
- 完成 Agent Tool 调用入口。
- 使用内存数据跑通业务闭环。

## 第 2 阶段：数据库与模板生成

- 接入 MySQL Repository 层。
- 接入模板变量表。
- 使用 poi-tl 或 docx4j 填充 Word 模板。
- 接入文件存储。
- 接入 PDF 导出。

## 第 3 阶段：知识库与审查

- 接入 Chroma。
- 对标准条款和历史合同做切片入库。
- 实现条款检索 Tool。
- 实现风险审查规则和引用依据。

## 第 4 阶段：权限、审批与审计

- 接入登录与权限。
- 完成合同审批流。
- 完成版本管理。
- 完成 AI Tool 调用日志。
- 完成操作日志。

## 第 5 阶段：上线

- 部署 MySQL、Redis、Chroma、MinIO。
- 部署后端服务。
- 部署前端静态站点。
- 配置 HTTPS、备份、监控、告警。
- 完成 UAT 和法务验收。
